# Agentic Trust Foundation

Open foundation for interoperable trust, delegation, identity, policy, and accountability in the agentic internet.

## Mission

Agentic Trust Foundation explores open standards and interoperable infrastructure for establishing trust and delegated authority between humans, agents, services, and organizations.

## Focus Areas

- Agent identity
- Delegated authority
- Trust and verification
- Policy
- Reputation
- Provenance
- Revocation
- Auditability
- Human approval
- Cross-domain interoperability

## Status

This project is in an early research and architecture phase.

We are currently studying the gaps between existing agent, identity, authorization, delegation, discovery, commerce, and payment standards.
