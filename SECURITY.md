# Security

Security-sensitive reports should not be disclosed in public issues before maintainers have had an opportunity to assess them. Use the private security reporting mechanism provided by the relevant repository when available.

For Agentic Trust Foundation, identity, delegation, authorization, trust, policy, revocation, provenance, auditability, and human approval are security-sensitive. For Agent-Pay, financial authorization, budgets, approvals, payment authentication, idempotency, provider operations, settlement, reconciliation, and ledgering are security-sensitive.
